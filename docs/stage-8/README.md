# Этап 8.0 — справочник статей и перенос «Финансы 25»

- `categories.csv` — новый справочник: тип (расход/доход), группа, статья (каждая — один раз), направление по умолчанию (Стадо / Корма / Реализация / Общехозяйственные), вид (тек — текущий, кап — капвложение, возврат — не выручка).
- `mapping.csv` — правила переноса строк Excel: старая группа (начало номера) и статья, слова в товаре или примечании (`!слово` — исключить), действие (`статья` или `долг`), новая статья, направление (пусто — по умолчанию статьи). Первое подошедшее правило побеждает. Этими правилами пользуется импорт (шаг 8.4).
- `private/Сопоставление статей.xlsx` (вне git: репозиторий открытый, а в файле — все строки учёта) — файл для владельца: новые статьи, «было → стало», каждая строка Excel, кошельки и долги, вопросы.
- `build_mapping.py` — пересобирает всё из `C:\Users\Иван\Yandex.Disk\КФХ\Финансы 25.xlsm` (только чтение) и проверяет, что каждая строка нашла статью и суммы сохранились до копейки: `PYTHONUTF8=1 python docs/stage-8/build_mapping.py` (нужен `openpyxl`). Справочник и правила — в начале скрипта; после правки — пересобрать.

Займы из листов «Доход»/«Расход» (10 строк) совпадают с реестром «Долги» по дате и сумме и не переносятся: займы берутся только из реестра.
